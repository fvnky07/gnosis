# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

The full text is available at the link above. By participating in this project — opening issues, submitting pull requests, joining discussions — you agree to uphold it.

## Reporting

Report violations privately to the maintainer at the email associated with the [@fvnky07](https://github.com/fvnky07) GitHub account. Reports are handled confidentially.

## Enforcement

The maintainer is responsible for clarifying acceptable behavior and will take appropriate action in response to any reported incident, up to and including removal from the project.
